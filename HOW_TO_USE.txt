🚀 TAREEQA 1: "1-Click Master Setup" (Sab Se Behtareen & Asaan!)
================================================================
Aapko bar bar manually server on karne ki zaroorat nahi:

1. Folder mein mojood is file par DOUBLE-CLICK karein:
   👉 OneClick_Setup.bat

Yeh Script Khud Sab Kuch Karegi:
  ✅ Python check karegi (agar nahi hai to khud install karegi)
  ✅ Saari zaroori packages (yt-dlp wagera) install karegi
  ✅ Windows Startup mein Silent Background Launcher set kar degi
  ✅ Browser se 1-click wake-up protocol (zdownloader://) enable karegi
  ✅ Aapke Desktop par "ZDownloader PRO" ka shortcut bana degi
  ✅ Server ko chup-chap background mein start kar degi!

Jab yeh poori ho jaye to bas Chrome Extension load kar lein (Step 3)!

----------------------------------------------------------------
🔄 AUTO-START & BACKGROUND SYSTEM:
----------------------------------------------------------------
- Har baar jab aapka PC on hoga, backend chup-chap background mein 
  bina kisi black CMD window ke khud start ho jayega.
- Agar kisi wajah se backend band bhi ho, to Chrome Extension ke 
  andar "🚀 1-Click Auto-Start Backend" button dabane par server 
  browser se direct on ho jayega!
- Agar auto-start khatam karna ho: "remove_autostart.bat" chala dein.

================================================================
⚡ TAREEQA 2: Manual / Normal Tareeqa (Optional)
================================================================
Agar aap khud manual chalana chahte hain:
1. "install_dependencies.bat" par double-click karein (1 time).
2. "start.bat" par double-click karein (Web app open hogi http://localhost:8000).
   Ya "start_app.bat" chala kar Desktop native window open karein.

================================================================
🧩 STEP 3: Chrome Extension Install Karna
================================================================
Browser mein YouTube, Facebook, Pinterest, Instagram wagera par 
direct download karne ke liye:

1. Google Chrome kholain aur address bar mein likhein:
   chrome://extensions/
2. Top-right corner par "Developer mode" toggle ko ON karein.
3. Top-left par "Load unpacked" button par click karein.
4. Is project folder ke andar jo "extension" folder hai, usay select karein.
5. Extensions menu mein ZDownloader ka Pin icon dabayein.
   Extension activate ho chuki hai!
